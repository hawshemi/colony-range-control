# Publishing

Version 1.1, revision 3, release candidate 1. Author: hawshemi.

The source package contains 17 numeric options, a preset selector, a master switch, Lua code, metadata, instructions and an original thumbnail updated with AI assistance.

The public GitHub repository is [hawshemi/colony-range-control](https://github.com/hawshemi/colony-range-control). No license has been selected or granted.

For local installation, close the game and back up the current mod folder. Replace that folder's contents with the files inside `mod`. Keep the existing LocalRangeExtender ID and keep only one installed copy. Existing per-category settings remain available under Custom.

For a future Paradox upload, open Main menu → Mod Editor, open this mod, Save, then Upload to Paradox. The editor may restart the game. The source zip is not a built ModContent.fpk. The game builds its own upload archive.

Before describing this release as stable, verify all categories in a new colony and an existing save. Confirm targets beyond their old range, planting at the enlarged forestation boundary, heat map changes, closed Stirling behavior, readable range reports, conflict warnings, presets, repeated save reloads and master-disable restoration. Automated tests do not prove these engine and UI behaviors.

Nothing has been published to Paradox Mods.
